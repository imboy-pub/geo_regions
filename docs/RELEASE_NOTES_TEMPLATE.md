# geo_regions research seed / 研究种子数据

This release contains ten country structures, ten country-catalog language packs and 100 country-language packs. Coverage varies by country and language. Read `docs/DATA_COVERAGE.md`, including CLDR draft quality and the 2023 mainland China statistical snapshot, before deployment.

本次发布为可追溯研究种子数据，包含 10 国结构、10 个国家清单语言包、100 个国家地区语言包。请先阅读 `docs/DATA_COVERAGE.md`，确认各国层级、语言缺口、CLDR 原始质量标记及中国大陆 2023 年统计快照限制。此说明不表示数据已获人工校审或达到生产发布标准。

Code uses BSD-3-Clause. Included data retains its own upstream licenses; retain notices under `licenses/third_party/` when redistributing. No pub.dev package is published by this workflow.

代码采用 BSD-3-Clause，数据保留其上游许可证。再分发时应保留 `licenses/third_party/` 中的许可声明。本流程不会发布 pub.dev 软件包。

Verify the ZIP SHA-256 against the attached checksum file. This is a draft release for maintainer review; publishing it is a separate action.

请核对附带 SHA-256 校验文件。本流程只创建供维护者检查的草稿 Release，公开发布另行操作。
