## 1. 审查对象和结论分开

[候选索引](candidates.json)中的 `sourceKind=official_announcement` 只是文献分类，不是著作权法适用结论。
`official_page_read` 只表示读到所指页面正文；材料使用依据、行政生效日期和实体继承关系必须分别判断。
本页只存链接、元信息、自写分析和未知项；没有原文归档、行政代码、字段提取件或真实迁移表。

| 判断 | 本轮可以记录的结果 | 不能顺带推出 |
|---|---|---|
| 来源与文献 | 原发、转载或转引页面，以及逐项日期出处 | 原批准文件已取得、转引内容完全准确 |
| 具体材料使用依据 | 许可条款或无需许可论证的候选路径、反证和待确认项 | 整个网站、附件、接口或所有下游用途都已清权 |
| 行政与迁移事实 | 哪些问题需要原文件、范围或身份连续证据 | 读到公告即可选择后继或填入生效日 |
| 项目实施与发布 | 现有准备范围已确认 | 实源导入、公开数据、成熟度提升或PR合并获准 |

## 3. 草湖公告：必要事实使用依据草稿

对应候选：`cn-reference-006`。整理人：Codex研究辅助；不是属主法律判断、专业意见或权利人授权。

| 项目 | 当前记录 |
|---|---|
| 具体材料 | 上表草湖公告的行政事项正文及其发布、落款元信息；不是整个网页或MCA接口 |
| 当前实际动作 | 保存链接和简短自写研究说明；未生成行政数据记录 |
| 未来拟评估动作 | 从确定材料独立记录必要行政事实，并评估公开Git、数据ZIP、离线App和商业集成的分发依据；本轮未批准这些数据用途 |
| 本卡不涵盖 | 网页模板、图片、编辑文案、未读附件、接口整表、未读或未评估的任何译文及第三方内容、统计汇编和既有2023基线的全部权利链 |
| 明确许可路径 | 尚未找到覆盖上述拟用范围的明确许可；网站声明的沉默不能补足授权 |
| 无需许可候选路径 | 就具体行政文件或独立事实评估著作权法第5条的适用；材料性质和必要事实范围尚待确认 |
| 事实不足 | 原批准文件、行政生效日期、代码发布和实体范围证据不全；即使权利问题解决，也不足以生成可靠迁移记录 |
| 待审结论 | **PENDING**；保持 `rightsStatus=not_reviewed_for_data_import`；真实数据提交和发布仍未批准 |

**法律事实：**[著作权法](https://ipc.court.gov.cn/zh-cn/news/view-6244.html)第5条列明特定国家机关文件及单纯事实消息等排除范围；第15条涉及有独创性选择或编排的汇编；第24条的研究使用有适用条件；第26、29条涉及许可及未授予权利。不能只以研究用途推导公开数据分发权。

**合理判断：**该页由自治区政府发布并以政府名义落款，针对批准设立事项；相较于整站、页面表达或接口汇编，限定到行政事项及必要事实更便于做第5条适用分析。这是有待审定的分析路径，不是把“官方”视为自动许可。

**需按实际用途确认：**具体材料是否落入法定排除范围、是否触及其他表达或汇编，访问条款及预期分发地域是否带来额外问题。若论证成立，记录其适用边界；若需要第三方许可，取得足够范围的许可，不能以属主风险接受替代。

## 5. 后续材料的最小审查记录

新增审查卡直接复用以下字段，不另建生产schema或自动法律门禁：

| 字段 | 填写要求 |
|---|---|
| 材料标识与观察 | candidateId、URL、发文主体/文号、正文或附件定位、核查日期、取得方式、原发/转载/转引；未归档就明确未归档 |
| 拟使用范围 | 明确材料子集、加工动作和下游渠道；注明未涵盖的附件、表达、汇编及地域 |
| 依据与反证 | 明确许可或具体无需许可论证，逐项列条款来源、成立理由、网站限制和仍缺证据 |
| 事实与迁移 | 日期各自出处、范围和身份问题；不用其他文件的施行条款补空值 |
| 待审结论 | 使用依据是否完成、专业确认/必要许可是否取得、残余风险及其明确范围；不得预填审批人或已批准状态 |
| 实施和发布 | 另记实源导入、数据发布和成熟度决定；限定准备与PR文档合并都不能替代它们 |
| 分发移交 | 列出实际必须随数据交付的来源、署名、许可或范围说明，以及触发重新评估的变化 |

如果无需许可依据成立，准确说明依据与范围，不虚构权利人授予BSD、CC0或其他许可。[LICENSE_POLICY](../../LICENSE_POLICY.md)要求原始代码和第三方数据分别处理；现有CN基线的来源义务仍保留。

**未来分发的交接条件：**当前[打包器](../../../tool/package_release.py)递归收录 `sources/`，但只收少量指定文档，**不自动收录本研究目录**。未来获准导入时，必须把必要的来源和使用说明交接到实际随包的来源/notice材料，并复核交付物；只在本页留下审查结论不足以完成下游通知义务。本轮不更改打包器、不放入任何待审原始或派生数据。
